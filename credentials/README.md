# Credentials

Everything in this folder except this README is git-ignored.

Place here:

- `gmail_client_secret.json` - OAuth client (type **Desktop app**) from Google Cloud Console → APIs & Services → Credentials, with the Gmail API enabled.
- `gmail_token.json` - created automatically the first time you authorize Gmail from the app. Delete it to re-authorize.

API keys (Gemini, Hunter) go in `.env`, not here.
